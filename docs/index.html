How to update a task

  1. Open a task and choose Update on GitHub.
  2. Edit its description to set Status, Owner, Due date, and notes.
  3. Use To do, In progress, or Blocked. Close the issue when it’s done.

GitHub access is required to edit. Published dashboard updates appear after the deployment finishes, usually within a few minutes. Refresh to load the latest deployment.

Owner names can be plain text; GitHub assignees are also supported. Dates use YYYY-MM-DD. No task changes are stored only in this browser.
